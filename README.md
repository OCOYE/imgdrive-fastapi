# IMG Drive.
A simple project to backup your photos using sqlite, sqlmodel, python and fastapi.

# Needed
1. Python3
2. sqlmodel, fastapi, aiofiles, pathlib, contextlib and jinja2.

**Recommended to install this packages using pip**

# How to execute?
1. Use the python venv

# How to use?
To acess terminal to search or rename: localhost:8000/docs
If you want to acess the gallery: localhost:8000
